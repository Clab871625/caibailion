# O Caibalion — Curso e Transcrição

Repositório com (1) a **transcrição** do audiolivro *O Caibalion* (legenda de YouTube,
com os timestamps removidos) e (2) a **estrutura de um curso** em português sobre a
obra e a filosofia hermética.

